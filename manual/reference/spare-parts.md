# REF-006: Spare parts

The existing [compatible spare parts](../../overview/what-we-do.md) and [3D printable parts](../../overview/our-features.md) pages contain the project's current findings.

When recording another part, include its function, manufacturer and model, VanMoof part number if known, compatibility evidence, source, related procedure, and whether fit has been verified on an S3.

## Type abbreviations

* **BHCS:** button-head cap screw
* **FHCS:** flat-head countersunk cap screw
* **SHCS:** socket-head cap screw

Record thread diameter, pitch, length measured from the correct datum, head style, drive type, material, finish, and captive washers where these can be verified. Add a related procedure and photograph as each fastener is encountered in the documented disassembly sequence.

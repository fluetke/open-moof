# Disassembly

Disassembly documents follow the chronological order in which parts are removed from the bicycle. Each procedure should identify prerequisites, tools, fasteners, electrical or hydraulic connections, hazards, and the storage or labelling needed for removed parts.

The current [full-disassembly record](../../repair-guides/full-disassembly.md) will become the top-level sequence. Existing component procedures provide detailed steps for:

* [removing the front wheel and hub motor](../../repair-guides/hub-motor/removing-the-front-wheel-and-hub-motor.md)
* [opening the hub motor](../../repair-guides/hub-motor/opening-the-motor.md)
* [removing the cable harness](../../repair-guides/cable-harness/README.md)

New chronological procedures should use `DEM-###` identifiers and link to the applicable fastener, tool, connector, and torque references.

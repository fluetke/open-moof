# Appendix

The appendix collects supporting material that does not belong in the procedural flow:

* parts lists
* reference photographs
* CAD files
* STL and other printable model files

The repository's current printable models are stored in [`parts/`](../../parts/), with preview and source information on the [3D printable parts](../../overview/our-features.md) page. Use descriptive filenames and link each asset back to its related procedure or reverse-engineering record.

# Assembly

Assembly follows the reverse order of disassembly but must be documented as an explicit procedure rather than relying on “reverse the previous steps.” Include cable and hose routing, connector checks, lubrication, fastener replacement requirements, tightening sequence, torque, adjustment, and a final functional test.

Use `MON-###` identifiers for assembly procedures. Link every step to the relevant [fastener](../reference/fasteners.md), [torque](../reference/torque-specifications.md), [tool](../reference/tools.md), and [connector](../reference/connectors.md) records.

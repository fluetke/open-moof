## Overview

openMOOF collects community knowledge about diagnosing, maintaining, and repairing VanMoof S3 bikes. Use the repair guides for step-by-step procedures, or consult the parts pages when looking for compatible replacements and printable parts.

The manual separates reference data, disassembly, assembly, maintenance, reverse engineering, and supporting files so that measurements and part details can be reused across procedures.
